# Assure Global Sourcing (AGS) Website

This website joins the supplied AGS artwork into one responsive HTML page.

## Included
- `index.html`
- `assets/` containing the supplied logo and all supplied slide artwork
- 3 hero banners rotate automatically every 10 seconds
- Sticky top navigation links to each corresponding sheet
- Mobile-friendly navigation
- No slide artwork has been recreated or redesigned

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `.nojekyll`, and the entire `assets` folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose the main branch and `/ (root)`.
5. Save and open the generated GitHub Pages URL.
